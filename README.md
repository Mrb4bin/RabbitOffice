# 🐇 Rabbit Office

Бесплатный офисный пакет без подписок для Windows, macOS, Linux и Android.

| Приложение | Что делает | Свой формат | Импорт / экспорт |
|---|---|---|---|
| **Rabbit Documents** | Текстовый редактор: стили, шрифт и абзац (отступы, интервалы, малые прописные), таблицы с изменяемой шириной столбцов, рисунки, фигуры, диаграммы, формулы, сноски, режим исправлений (принять/отклонить), примечания, оглавление, колонтитулы, номера страниц, подложка, буквица, переносы, защита от изменений, поиск и замена, режим фокуса | `.rdoc` | DOCX ⇄ (с исправлениями и сносками), HTML, Markdown, TXT, PDF |
| **Rabbit Xel** | Таблицы: 150+ функций (по-русски и по-английски: `СУММ`/`SUM`, `ВПР`/`VLOOKUP`…), имена диапазонов, сводные таблицы, проверка данных с выпадающими списками, подбор параметра, фильтры по значениям и условиям, сортировка, условное форматирование, стили ячеек и «форматировать как таблицу», диаграммы, гиперссылки, закрепление областей, объединение ячеек, примечания, защита листа, параметры печати | `.rxel` | XLSX ⇄, CSV ⇄, HTML, PDF |
| **Rabbit Point** | Презентации: 8 тем, 7 макетов, 20 фигур с градиентами, группировка, таблицы, диаграммы, рисунки с эффектами, видео и звук, значки, переходы, анимации, автосмена и зацикливание показа, перо и лазерная указка, режим докладчика, сортировщик | `.rpt` | PPTX ⇄, PDF, PNG, HTML-презентация |
| **Rabbit Desk** | Онлайн-доска (аналог FigJam): стикеры с авторами и голосованием, 11 фигур, связи, линии и стрелки, рисование, секции, комментарии с ответами, реакции, общий таймер, мини-карта, выравнивание, курсоры соавторов | `.rdesk` | PNG, SVG |

Во всех программах: восстановление несохранённых документов после сбоя, автосохранение, проверка орфографии (русский и английский), шаблоны.

Оформление — 4 темы: **Стандартная**, **Стандартная тёмная**, **Liquid Glass**, **Liquid Glass тёмная** (Файл → Параметры или значок палитры в заголовке).

## Совместная работа в Rabbit Desk — 3 режима
1. **По IP-адресу** — настольное приложение становится хостом (порт 47800, опциональный PIN), остальные вводят `IP:порт`.
2. **Локальная сеть** — хост объявляет сессию по UDP (порт 47801), клиенты видят её в списке и подключаются в один клик. Android/браузер находят сессии сканированием подсети.
3. **Через сервер** — доски хранятся на вашем сервере Rabbit Office и доступны всем его пользователям.

Синхронизация — по WebSocket, объекты сливаются по принципу «последняя запись побеждает», при обрыве связи клиент переподключается и досылает изменения.

## Rabbit Office Server (свой сервер на Linux)
Сервер ставится на **ваш** VPS — никаких облаков разработчика.

```bash
sudo ./server/install.sh
```

Установщик поставит Node.js, создаст службу `rabbit-office` и запустит мастер, который спросит:
- название сервера;
- режим: **хранилище**, **доски** или **оба**;
- домен — если указан, сертификат Let's Encrypt получается и продлевается автоматически (нужны A-запись и открытые порты 80/443);
- логин и пароль администратора.

Дальше пользователи создаются в веб-панели `https://ваш-домен/admin` (логин + сгенерированный пароль, роль, квота) или из консоли:

```bash
sudo -u rabbit RABBIT_DATA=/var/lib/rabbit-office rabbit-office user add ivan
```

Сервер также раздаёт весь офис в браузере по своему адресу. В приложениях: аватар → «Подключить сервер»; там же пользователь меняет свой пароль.

Обслуживание:
- обновление — повторно запустите `sudo ./server/install.sh` из новой версии: данные и настройки сохранятся;
- резервная копия — кнопка в админ-панели или `rabbit-office backup`, восстановление — `rabbit-office restore <архив>`;
- Docker: `docker compose -f server/docker-compose.yml up -d` (из корня проекта).

## Готовые сборки (GitHub Actions)
Установщики для всех ОС собирает GitHub по файлу `.github/workflows/build.yml`:
- **Actions → Build → Run workflow** — собрать и скачать файлы со страницы запуска (раздел Artifacts);
- выпустить версию: поднимите `version` в `desktop/package.json` и `android/package.json`, затем создайте тег `v1.0.0` (например, в **Releases → Draft a new release → Choose a tag**) — файлы появятся в этом релизе.

| ОС | Файлы |
|---|---|
| Windows | `Rabbit Office Setup x.y.z.exe` (установщик), `Rabbit Office x.y.z.exe` (портативная) |
| macOS | `.dmg` для Intel и Apple Silicon (при сборке не на Mac — `.zip`) |
| Linux | `.AppImage`, `.deb`, `.rpm` |
| Android | `Rabbit-Office-x.y.z.apk` |

Пока у проекта нет сертификатов разработчика, поэтому:
- Windows SmartScreen предупредит о неизвестном издателе → «Подробнее» → «Выполнить в любом случае»;
- macOS: перенесите приложение в «Программы» и при первом запуске откройте через правый клик → «Открыть». Если система пишет, что приложение «повреждено», выполните в Терминале `xattr -cr "/Applications/Rabbit Office.app"`, а если и после этого не запускается (сборки `.zip`, сделанные не на Mac, не подписаны) — `codesign --force --deep --sign - "/Applications/Rabbit Office.app"`;
- APK подписывается ключом проекта, если в **Settings → Secrets and variables → Actions** добавлены секреты `ANDROID_KEYSTORE_BASE64` (файл ключа в base64) и `ANDROID_KEYSTORE_PASSWORD`; без них — отладочным ключом, и перед установкой новой версии старую придётся удалить.

Ключ подписи Android лежит в `android/keystore/` (в репозиторий не попадает). Сохраните копию этой папки: без ключа выпустить обновление, которое встанет поверх старой версии, нельзя. Значение для секрета `ANDROID_KEYSTORE_BASE64` (PowerShell):
```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("android\keystore\rabbit-office-release.jks")) | Set-Clipboard
```
Пароль — строка `storePassword` в `android/keystore/keystore.properties`.

## Сборка приложений вручную
```bash
cd desktop && npm install && npm start          # запуск на компьютере
cd desktop && npm run dist:win                   # установщик Windows (dist:mac / dist:linux)
cd android && npm install && npm run init && npm run open   # проект Android Studio
```
Готовые файлы появляются в `desktop/dist/`: `Rabbit Office Setup 1.0.0.exe` (установщик) и `Rabbit Office 1.0.0.exe` (портативная версия). Сборка `.dmg` для macOS возможна только на Mac; на Linux (или в Docker-образе `electronuserland/builder`) собираются Linux-пакеты и macOS-версия в `.zip`.
Если сборка на Windows падает с ошибкой `Cannot create symbolic link` (winCodeSign), запустите терминал от администратора или включите «Режим разработчика» Windows — либо распакуйте архив winCodeSign из `%LOCALAPPDATA%\electron-builder\Cache\winCodeSign` в папку `winCodeSign-2.6.0` рядом, пропустив каталог `darwin`.

Веб-версия для разработки: `node scripts/dev-server.js` → http://localhost:5173

## Структура
- `web/` — общий код всех 4 приложений и стартового экрана (чистые ES-модули, без сборки)
- `shared/` — WebSocket-сервер и комната совместной работы (общие для сервера и настольного хоста)
- `server/` — Rabbit Office Server, админ-панель, CLI, установщик
- `desktop/` — оболочка Electron (Windows/macOS/Linux)
- `android/` — оболочка Capacitor (Android)
- `.github/workflows/` — автоматическая сборка для всех ОС

## Известные ограничения версии 1.0
- На Android и в браузере можно подключаться к сессиям Desk, но не проводить их — хостом в режимах «по IP» и «локальная сеть» выступает настольное приложение или сервер.
- Импорт DOCX/XLSX/PPTX переносит основное содержимое и оформление; сложные элементы (SmartArt, макросы, сводные таблицы, анимации PPTX) пропускаются.
- Интерфейс пока только на русском.
- Логотипы — временные цветные квадраты.
